🍔 Burn Out Burger Website

A full-stack restaurant website developed as part of the Web Programming (CS361) course. The project demonstrates building a dynamic web application using HTML, CSS, JavaScript, PHP, and MySQL.  

⸻

📌 Project Overview

Burn Out Burger is a modern restaurant website that allows users to:

* Explore the menu
* Place orders online
* Contact the restaurant
* View customer reviews
* Manage orders through an admin panel

The project covers both frontend and backend development, including database integration and user interaction.  

⸻

🚀 Features

🌐 Frontend

* Responsive design using HTML5 & CSS3
* Consistent navigation across all pages
* Modern UI with animations and hover effects
* Multiple pages (Home, About, Menu, Contact, Order, Customers, Admin)  

⚡ JavaScript

* Form validation (Contact & Order forms)
* Error popup messages with detailed validation
* Dynamic price calculation for orders
* Interactive UI elements  

🗄️ Backend (PHP & MySQL)

* Database connection using mysqli
* CRUD operations:
    * Insert orders
    * Retrieve data
    * Update orders
    * Delete records
* Admin dashboard for managing orders  

⸻

🏗️ Technologies Used

* HTML5
* CSS3
* JavaScript
* PHP
* MySQL
